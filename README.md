# Week 1 (0306) - 파이썬 소개

### 인터프리터

- 파이썬은 인터프리터 언어로서 코드를 한 줄 실행할 때마다 컴퓨터가 이해할 수 있는 언어로 실시간 번역을 한다. 

- 인터프리터와 달리 컴파일러는 컴파일(Compile)이라는 과정을 거쳐 프로그램 전체를 컴퓨터가 읽을 수 있는 파일로 통째로 먼저 번역해 둔다. 

---

## 📌 1주차 핵심 학습 내용

1주차 핵심 개념들을 학습하고 적용해 보았습니다.

* **변수의 개념과 활용**: 데이터를 저장하는 메모리 공간의 개념을 이해, 사물함에 이름표를 붙이듯 변수를 선언하여 원하는 값을 할당(`=`)하는 방법 숙지
* **기본 연산 및 수식**: 사칙연산(`+`, `-`, `*`, `/`), 거듭제곱(`**`)과 지수 표기법(`4E13`)을 사용하여 수식을 코드로 표현
* **데이터 타입(자료형)**: 정수(Integer)와 실수(Float)의 차이를 이해, 상황에 맞는 자료형을 선택하여 연산에 사용
* **출력문(`print`) 활용**: 변수에 저장된 값과 문자열을 조합, 문장으로 출력하는 방법을 학습
